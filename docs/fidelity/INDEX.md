# Fidelity index

Generated by `scripts/verification/render_fidelity_index.py`. Do not edit by hand.

Each metric's status comes from `MetricInfo.fidelity`, which
`tests/test_metadata.py` pins to its `sources/SOURCES.yaml` status — so a
metric cannot claim a fidelity its sources do not support, and cannot stay
`unaudited` once they have been read.

## Statuses

- **faithful** — same formula, same protocol; any difference is a documented access-mode necessity that does not change the statistic.
- **adaptation** — same underlying comparison, different access mode or scoring path that *can* change numbers.
- **original** — BiasScope's own operationalization, inspired by a cited idea; does not carry the cited paper's metric name.
- **mismatch** — implements a different statistic under the cited name — **must be fixed before release**.
- **unaudited** — sources not yet read, so **no fidelity claim is made**; PLAN.md Section 4.0 forbids assigning a status before reading the paper and the reference code.
