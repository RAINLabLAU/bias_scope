# Multilingual support

Some metrics can run in more than one language, and BiasScope says which ones and what
makes that true. A metric's `MetricInfo.languages` is backed by the authors' own shipped
files, not by a claim: CBS declares 12 languages because the authors' `configuration.py`
has 12, and HONEST declares 6 because its `resources/` folder has 6 template files.

`recommend_metrics(access, language="fr")` offers only the metrics that declare that
language, and `explain_exclusions` reports `no fr resources` for the rest.

## Datasets

Loaders for multilingual bias datasets live in `bias_scope.multilingual`. **Nothing is
redistributed.** Datasets with non-commercial or unstated licenses are loader-only, and
every loader reads a path you already have. When the files are missing it raises an error
naming the source, the license, and where to get it.

```python
from bias_scope.multilingual import load_kobbq, load_mbbq

rows = load_mbbq("path/to/MBBQ", language="es", category="Age")
korean = load_kobbq("path/to/KoBBQ", split="test")
```

| Loader | Dataset |
|---|---|
| `load_mbbq(root, language, category, *, control)` | MBBQ |
| `load_kobbq(root, split)` | KoBBQ |
| `load_cbbq(root, category, condition)` | CBBQ |
| `load_crows_pairs_multilingual(path, language)` | French and English CrowS-Pairs extension |

## What is not yet claimed

Loaders exist and each declared language is backed by a shipped file. What remains is
running every metric end to end in a non-English language and recording the result. Until
that is done, treat a non-English score as unvalidated and check the metric's fidelity
note.
